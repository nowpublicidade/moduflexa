# Andar 05 — Projeto completo

Estado único (não é par fechado/aberto) — é o clímax visual da sequência
de andares, depois do qual a narrativa muda de produto para marca
(01-page-structure.md §11, 06-asset-guide.md §33). Deve ser a imagem mais
aspiracional depois do hero.

## Como gerar

Um só arquivo, sem edição/par — gere `hero.md` diretamente.

## Formato de entrega

Landscape, próximo de 3:2 (o site usa esta imagem em full-bleed, então
alguma margem extra nas bordas ajuda no recorte final). PNG ou JPG,
nomeie `hero.png`.
