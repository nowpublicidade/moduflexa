# Andar 03 — Receber sem perder espaço

Diferente do Andar 01 de propósito: mesmo conceito de "quarto de hóspedes
escondido", mas em outro cômodo (aqui, um home office/hobby room que vira
quarto de visitas) e outro enquadramento, para não repetir a composição
já usada. Ver `docs/03-storytelling.md` §24-25 — o foco narrativo aqui é a
situação social (receber alguém), não a metragem.

## Como gerar (ordem importa)

1. Gere **everyday.md** primeiro (ambiente no uso cotidiano).
2. Para **hosting.md**, use a imagem do uso cotidiano como referência
   (image-to-image / edição) e peça só a mudança descrita.
3. Antes de me devolver: sobreponha as duas em 50% de opacidade. Se algo
   fixo deslocar, o par não está pronto.

## Formato de entrega

Landscape, próximo de 3:2. PNG ou JPG, nomeie `everyday.png` / `hosting.png`.
