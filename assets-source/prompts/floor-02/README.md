# Andar 02 — Home office retrátil

Mesma lógica do Andar 01 (já aprovado — ver `../floor-01/`). Este par usa o
mesmo vocabulário de material/ferragem da cama retrátil (madeira clara,
trim de alumínio escovado, perna metálica branca dobrável, pads laranja),
porque é a mesma linguagem de produto da marca — só o móvel muda de cama
para mesa.

## Como gerar (ordem importa)

1. Gere **closed.md** primeiro.
2. Para **open.md**, use a imagem fechada como referência (image-to-image
   / edição) e peça só a mudança descrita — não gere do zero.
3. Antes de me devolver: sobreponha as duas em 50% de opacidade. Se algo
   fixo (cama, janela, criado-mudo, tapete) deslocar, o par não está
   pronto — gere de novo.

## Formato de entrega

Landscape, próximo de 3:2. PNG ou JPG, nomeie `closed.png` / `open.png`.
